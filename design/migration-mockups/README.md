# ACX City — Migration Mockups (Revamp 01)

High-fidelity, self-contained HTML mockups translating the five reference
screens in `Migration_Planning.docx` (screenshots of an AI resume builder)
into **ACX City's own product and brand**.

**Open [`acx-city-migration-mockups.html`](./acx-city-migration-mockups.html)
in any browser** — no build step, no external assets, fully responsive.
Static PNG exports of each screen live in [`exports/`](./exports/).

## Direction

> Apple's calm × Instagram's pulse, with one thin vermilion hairline
> running through everything.

- **Thin orange borders** — the signature: `1px rgba(255,77,0,.32)` on every
  card, chip, frame, field and drop zone. The only 1.5px line in the system
  marks the *selected* voice.
- **Apple** — SF Pro system stack, tight display tracking, generous
  whitespace, frosted nav, `#F5F5F7` quiet sections, pill buttons.
- **Instagram** — story rails and gradient rings (amber → vermilion → blush →
  iris), story-segment steppers, feed-style review cards with hearts.

## The five screens (source → revamp)

| # | Source screenshot (resume builder) | Rebuilt as (ACX City) |

A full pattern-by-pattern table lives in the deck's **Migration map** section.

## Design tokens (quick reference)

| Token | Value | Use |
|---|---|---|
| Vermilion 500 | `#FF4D00` | actions, accents, hairlines |
| Ember 600 | `#D93F00` | orange text on white (AA) |
| Ink | `#1D1D1F` | type, dark bands |
| Night | `#0B0B0F` | studio & ACX bands |
| Fog / Cream | `#F5F5F7` / `#FFFAF6` | quiet sections / warm fills |
| Hairline | `1px rgba(255,77,0,.32)` | every card, chip, frame, field |
| Story gradient | `#FFC24B → #FF5A1F → #E9308F → #8A3FFC` | rings, steppers, moments of delight |
