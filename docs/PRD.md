# Chambers PRD — studio + house language

**Date:** 2026-09-16  
**Lane:** Resume + cover letter studio on letter paper, plus the token/drop archive.

## One sentence

Chambers is a local-first resume and cover letter studio that prints like you meant it, and the house visual language those sheets speak.

## What success looks like

1. Open Studio, pick Editorial or Classic, and know it is Mangu in three seconds.
2. Paste a posting, hit Tailor, see **What changed** immediately — no invented jobs.
3. Print / PDF from the browser at US Letter, 816px design width.
4. Other Mangu apps still import `tokens/tokens.css` without forked hex.

## Non-goals

- Accounts, cloud sync, or a job tracker.
- Inventing employers, dates, degrees, or metrics.
- Selling a subscription.

## MVP (this pass)

Vite + React 19 + TanStack Router studio: start, six papers, instant local tailor, cover letter, ATS, print CSS. Tokens and HTML drops kept.

## Rendering bar

Letter width 816px. Tight display tracking. Vermilion section labels (ink on Classic). Print stylesheet. That is how Chambers beats generic builders without becoming a canvas app.
